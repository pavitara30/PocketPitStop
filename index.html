Recording a session

  
    
    
  1. Mount the phone rigidly to the chassis, not the steering column. Nobody touches it while driving.
    2. 
    
  2. Open this page, tap Start recording, and allow motion and location access.
    3. 
    
  3. Keep the kart still for the 10-second countdown. That parked moment tells the software which way is down.
    4. 
    
  4. Drive. Keep Safari open with the screen on; if the screen locks, recording pauses. If your phone can't keep the screen on by itself, set Auto-Lock to Never (Settings, Display & Brightness) for the session.
    5. 
    
  5. Tap Stop and analyse. Save the recording if you want to keep it.
    6. 
  

  
For long sessions, the free Sensor Logger app is more robust: it records in the background, at a higher sample rate. Turn on Accelerometer, Gravity, Gyroscope and Location, export as zipped CSV, and analyse it above.


  
How it works

  
    
    
  1. Align. The phone's axes don't match the kart's. Gravity while parked gives "down"; the direction whose acceleration best explains GPS speed changes gives "forward".
    2. 
    
  2. Sync. Motion sensors run at 100 Hz, GPS at about 1 Hz and late. Everything is resampled onto one timeline, and the GPS delay is measured by cross-correlation.
    3. 
    
  3. Filter. Karts have no suspension, so a low-pass filter strips out engine vibration (the spectrum in the dashboard shows where it sits).
    4. 
    
  4. Fuse. A Kalman filter combines fast-but-drifting accelerometer speed with slow-but-steady GPS speed. A complementary filter combines gyroscope and gravity for roll and pitch.
    5. 
    
  5. Detect. Thresholds find braking, cornering and flat-out stretches. Laps are timed where the GPS track crosses the start/finish line, splitting the gap between fixes using the fused speed.
    6. 
    
  6. Check. Parked reading should be 1 g, Kalman speed should track GPS, and lap times are compared against an IR lap counter.
    7. 
  


  
Runs on Pyodide with numpy, scipy, pandas and matplotlib. The first run downloads about 40 MB; after that it's cached.
